O que o JavaScript pode fazer?

Explore cada capacidade clicando nos botões abaixo. Depois, veja o código que faz a mágica acontecer.

1. Alterar conteúdo 2. Alterar atributos 3. Alterar estilos 4. Ocultar elementos 5. Exibir elementos
1

Alterar o conteúdo HTML

innerHTML

O JavaScript pode trocar o texto (ou o HTML inteiro) dentro de qualquer elemento da página usando a propriedade innerHTML.

Resultado

O JavaScript pode alterar o conteúdo de um elemento HTML.

2

Alterar atributos HTML

.src / .href

Atributos como src, href e alt também podem ser modificados dinamicamente. Aqui simulamos uma lâmpada ligando e desligando.

Resultado
Lâmpada desligada
3

Alterar estilos CSS

.style

Com element.style.propriedade você muda qualquer regra CSS diretamente pelo JavaScript — cor, tamanho, fonte, margem e muito mais.

Resultado

O JavaScript pode alterar o estilo visual de qualquer elemento.

4

Ocultar elementos HTML

display = 'none'

Definir style.display = 'none' faz o elemento desaparecer da página — como se ele não existisse no layout.

Resultado

Este parágrafo vai sumir quando você clicar no botão abaixo.

5

Exibir elementos HTML

display = 'block'

O oposto também é possível: um elemento que começa oculto no HTML pode ser revelado com style.display = 'block'.

Resultado
